### Hangman project

Desarrollamos en equipo un juego del ahorcado en Python que se
ejecuta en consola. El jugador debe descubrir una palabra o frase
antes de alcanzar el máximo de errores permitido.

Este proyecto forma parte del curso Certificado de Desarrollo de Soluciones Digitales con IA de la Universidad Tecnológica de Uruguay (UTEC). 

Es el cierre del módulo dedicado al lenguaje Python. Busca implementar lo aprendido durante el recorrido, como: 

* Aplicar estructuras de control (condicionales y bucles) para gestionar el flujo del juego.
* Usar funciones para encapsular y estructurar la lógica.
* Utilizar estructuras de datos como cadenas y listas.
* Implementar conceptos básicos de programación orientada abjetos.
* Usar módulos e imports para separar el código en varios archivos.
* Manejar la entrada/salida de usuarios y archivos de texto.
* Leer y validar la entrada del usuario desde la línea de comandos.
* Practicar depuración básica y resolución de problemas mediante una ea del mundo real.
